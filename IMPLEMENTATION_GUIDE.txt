## If Something Goes Wrong

### Database Won't Update
```powershell
# Reset database
cd C:\Users\anwar\Downloads\FileOrganizerA\WpfApp1\WpfApp1
dotnet ef database drop -f
dotnet ef database update
```

### Build Fails
```powershell
cd C:\Users\anwar\Downloads\FileOrganizerA\WpfApp1\WpfApp1
dotnet clean
dotnet build
```

### App Still Freezes
- Make sure you're running the newly built version
- Check that Task Manager shows high CPU during operations
- Clear Visual Studio cache: `bin/` and `obj/` folders
